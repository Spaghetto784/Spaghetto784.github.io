# Matthieu Greiner portfolio design system

Implemented in `site.css` (tokens, components) and `site.js` (motion, i18n, theme, index tree). Pages are generated by hand-editing the HTML; there is no build step.

## Brand and mood
- Editorial, calm, "agency dossier": warm paper, near-black ink, hairline rules, one orange accent. No glow, no frosted cards, no gradients.
- The site reads as a file system: sections are folders (`/experience`, `/projects`), a thin tree on the left is both the index and the "you are here" marker.

## Themes
- Light is the default (`#fbfaf6` paper, `#12110f` ink). Dark is opt-in via the bar toggle (`#0e0e0c`, `#f1eee6`).
- The choice is stored in `localStorage.portfolioTheme`; `<html data-theme>` is set before first paint. Theme changes cross-fade colours (no brightness jump).
- Accent: `#ff5a1f` (dark: `#ff7a3d`). Use it for marks, dots, underlines and buttons with dark text. For accent *text* use `--accent-ink` (`#c2410c`, dark `#ff9461`) to keep contrast.

## Type
- Display: Instrument Serif (roman + italic). One italic accent word per heading, coloured `--accent-ink`.
- Text: Geist. Labels, dates, paths, tags: Geist Mono, uppercase with +0.06em tracking.
- Tracking is size-specific: hero `-0.04em`, section headings `-0.03em`, card titles `-0.02em`, body `0`, small mono labels positive.

## Layout
- `.shell` = fixed-width rail (13.5rem) + main column, max 80rem. Below 68rem the rail becomes an "Index" menu that materialises from its button.
- Sections: hairline rule that draws in on reveal, mono `NN /path` tag, serif heading, then rows. Rows are hairline-separated grids (meta column + content), never boxed cards.

## Motion
- Springs (`Site.Spring`, damping ratio + response) drive the folder open/close in the tree, the language thumb and the research sheet. Default damping `1.0`; bounce only after a flick.
- The research sheet tracks the pointer 1:1, projects momentum on release, rubber-bands at the top edge and exits along its entry path.
- Hero lines rise from a mask once; sections fade up once. No looping or full-viewport motion.
- Press feedback starts on pointer-down. Respect `prefers-reduced-motion` (cross-fades), `prefers-reduced-transparency` and `prefers-contrast`.

## Language
- EN lives in the markup; FR in each page's `Site.i18n.register({...})`. `Site.i18n.missing()` lists untranslated keys.
- File names in the tree (`about.md`, `lre-research.md`) are identifiers and stay in English.
