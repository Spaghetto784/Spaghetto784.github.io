# Component inventory

This is a static HTML portfolio; there is no JavaScript component directory.

- `GlassCard`: translucent dark card with a low-elevation hover lift.
- `SiteNavigation`: fixed header with centred desktop navigation and a compact mobile drawer.
- `SkillPreviewCard`: icon inside a tinted circular badge and a concise skill label.
- `ActionButton`: rounded primary or glass secondary CTA.
- `CategoryChip`: compact uppercase status/category label.

The Skills page should reuse these patterns rather than introduce a separate visual language.
