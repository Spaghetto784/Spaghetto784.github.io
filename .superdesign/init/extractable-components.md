# Extractable UI patterns

- **SiteNavigation** — fixed glass wrapper, desktop-centred link group, action group and mobile drawer.
- **GlassCard** — surface, border, blur, hover elevation and focus-safe interactive variations.
- **SkillTile** — icon badge, title, category label, confidence or usage note, and a short evidence line.
- **SectionHeading** — Space Grotesk heading with optional gradient word and muted intro copy.
- **FooterCTA** — compact contact/Calendly invitation.
