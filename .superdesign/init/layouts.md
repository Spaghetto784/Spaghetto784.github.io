# Layouts

The shared page shell is a fixed translucent navigation above a dark, radial-gradient page background, followed by full-width sections containing a `max-w-6xl` content container. The header contains a personal logo at left, centred primary navigation on desktop, actions at right, and a mobile drawer below 1280px.

The proposed Skills page uses the same shell: breadcrumb/back link, editorial hero, category sections, and a compact closing CTA.
