# Theme assets and tokens

- Fonts: Google-hosted Inter and Space Grotesk.
- Icons: Font Awesome 6.4.
- Animation: AOS, with reduced-motion override in `responsive-enhancements.css`.
- Photography: local `profile.webp`; technical tile icons should use Font Awesome or lightweight text marks, not a heavy image library.

Tailwind is loaded from CDN and extended with `accent: #6366f1`, `dark: #0f172a`, plus the display and body font families.
