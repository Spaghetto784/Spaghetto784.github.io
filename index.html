02

wlkom-rootkit

A Linux kernel rootkit in C, built in a team of four for EPITA's systems course inside an isolated two-VM QEMU lab: syscall hooking, hiding the module from lsmod, persistence and an authenticated TCP control channel. Writing one is the fastest way to learn what a detection tool has to catch.

View the source
rootkit/src/hide-rootkit/hide_rootkit.cC
// Hide from lsmod: unlink this module
// from the kernel's list of modules.
void wlkom_erase_from_list(
    struct list_head *prev,
    struct list_head *next)
{
    prev->next = next;
    next->prev = prev;
}
